# DDoS Protection

## What is a DDoS Attack?

DDoS stands for Distributed Denial of Service.

A DDoS attack attempts to overwhelm a service, application, or network with a large amount of malicious traffic so that legitimate users cannot access the service.

## Simple Example

Imagine a bank has one teller serving customers.

If thousands of fake customers suddenly enter the bank and continuously request service, the teller becomes overwhelmed.

Legitimate customers may no longer be able to receive service.

This is similar to how a DDoS attack overwhelms a cloud service.

## Types of DDoS Attacks

### 1. Volumetric Attacks

These attacks attempt to overwhelm network bandwidth with a large volume of traffic.

### 2. Protocol Attacks

These target network and transport protocols such as TCP and UDP.

### 3. Application Layer Attacks

These target applications and application-layer services.

## Azure DDoS Protection

Azure provides DDoS protection capabilities to help protect Azure resources from DDoS attacks.

Two protection options discussed in the class are:

- DDoS IP Protection
- DDoS Network Protection

## DDoS IP Protection

DDoS IP Protection provides protection for individual public IP resources.

## DDoS Network Protection

DDoS Network Protection is designed for broader protection of Azure virtual networks and is suitable for larger enterprise environments.

## Key Takeaway

DDoS protection helps distinguish legitimate traffic from malicious traffic and helps maintain service availability during attacks.
