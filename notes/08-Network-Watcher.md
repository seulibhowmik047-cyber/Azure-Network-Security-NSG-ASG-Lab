# Azure Network Watcher

## Overview

Azure Network Watcher provides tools for monitoring, diagnosing, and troubleshooting Azure networking.

## Purpose

Network Watcher helps administrators understand network connectivity and identify networking problems.

## Common Capabilities

Examples include:

- Connection troubleshooting
- Network topology
- IP flow verification
- NSG diagnostics
- Packet capture
- Network monitoring

## IP Flow Verify

IP Flow Verify can help determine whether traffic is allowed or denied by an NSG.

## Connection Troubleshoot

Connection troubleshooting can help diagnose connectivity problems between Azure resources.

## Network Topology

Network topology provides a visual representation of network resources and their relationships.

## Key Takeaway

Network Watcher is an important troubleshooting and diagnostic tool for Azure network environments.
